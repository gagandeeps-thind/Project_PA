# Arise Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Discover tab with Arise: a Mapbox map for runs, walks, hikes and trails, public routes, domains you can claim and attack, heatmaps and terrain layers.

**Architecture:** Backend: one router `routers/arise.py` over pure rules in `services/arise.py`, two migrations. Shared KMP: `AriseRepository` + `AriseViewModel`. Android: `ui/arise/*` on the Mapbox Compose extension. Existing run recording, course trimming and camera exercise sets are reused.

**Tech Stack:** FastAPI/SQLAlchemy/Alembic, Kotlin Multiplatform, Jetpack Compose, Mapbox Maps SDK 11.28.0.

**Spec:** `docs/superpowers/specs/2026-11-01-arise-design.md`

## Global Constraints

- Mapbox `com.mapbox.maps:android-ndk27:11.28.0` and `com.mapbox.extension:maps-compose-ndk27:11.28.0` from `https://api.mapbox.com/downloads/v2/releases/maven` (no credentials).
- Token `MAPBOX_ACCESS_TOKEN` from `config/environments/local.properties` (gitignored) → string resource `mapbox_access_token`. Never committed.
- Activity types: `run`, `walk`, `hike`, `trail`.
- Arise never touches crystals; the v1 vault fields are untouched.
- New code in new files; edits to `OsirisRoot.kt`, `AppGraph.kt`, `models.py`, `main.py`, `schemas.py`, `openapi.json`, `gate.sh` are diffed against agy's work first and staged by explicit path.
- Each phase: gate passes (`.claude/hooks/gate.sh`), commit, `git push origin master`.

## Review Focus

1. A run with fewer than 2 points or zero duration claimed as a domain → 422, never a crash.
2. A non-loop run (finish > 50 m from start) used to claim → 422 `NOT_A_LOOP`.
3. Attacking your own domain → 409; attacking with someone else's run → 404.
4. Shared heatmap cells with 1–2 distinct players are never returned.
5. No Mapbox token in the build → the map shows a "Map unavailable" message instead of crashing.
